# CS-320-Software-Testing-and-Automation

# CS 320 Portfolio Reflection

## How can I ensure that my code, program, or software is functional and secure?

I can make sure my software works correctly by testing it regularly and checking that it meets the requirements. Unit testing helps me test individual parts of the program and identify errors before they become bigger problems. I can also test different situations, including invalid inputs and unexpected values. To improve security, I should validate user input, handle errors properly, and make sure the program does not expose sensitive information. Testing throughout development helps me create software that is more reliable and secure.

## How do I interpret user needs and incorporate them into a program?

I interpret user needs by carefully reviewing the requirements and understanding what the program is expected to do. I can break the requirements into smaller tasks and use them to guide the design and development process. For example, when developing the contact service, I needed to make sure that contacts could be created, updated, and deleted while following the required rules. I used these requirements to guide my code and tests. This helps ensure that the final program meets the user's expectations.

## How do I approach designing software?

I approach software design by understanding the requirements first and planning how the different parts of the program will work together. I try to keep the code organized by separating responsibilities into different classes and methods. I also consider possible errors and how the program should handle them. Writing unit tests helps me check whether my design works as expected and makes it easier to find and fix problems. These projects helped me understand the importance of planning, testing, and following requirements when developing reliable software.
